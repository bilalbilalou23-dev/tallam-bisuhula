تطبيق تعلّم بسهولة — نموذج تجريبي
المحتويات: واجهة عربية RTL، أقسام مواد، مثال تدريب كتابة بالرسم بالإصبع، وسؤال تفاعلي.
هذا المشروع مصدر أولي وليس ملف APK جاهزًا.
لإنشاء APK:
1) ثبّت Android Studio على كمبيوتر.
2) افتح مجلد TallamBisuhula في Android Studio.
3) اسمح له بتنزيل Gradle ومكونات Android SDK المطلوبة.
4) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5) بعد انتهاء البناء، افتح رابط Locate في إشعار البناء للعثور على ملف APK.
ملاحظة: بعض صفحات المواد نماذج أولية، وليست محتوى منهج رسمي كاملًا. لا يحتاج هذا النموذج إلى الإنترنت حاليًا لأن محتواه محلي؛ يمكن ربطه بمحتوى إنترنت لاحقًا.
